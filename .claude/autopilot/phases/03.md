# Phase 03 — Build Lesson 11, and read what came out

Same procedure as Lesson 10's build phase, on Lesson 11. You did not write this
lesson, which is the point of doing it in a separate phase.

    cd ~/work/shams/esl && export PATH="$PWD/.venv/bin:$PATH"
    cat docs/LESSONS-10-12-PROGRESS.md
    cd lessons/lesson-11 && python build.py --check && python build.py --plan

Read `docs/LESSONS-10-12-BRIEF.md` §"Lesson 11" so you know what the lesson was
supposed to be before you judge what it is.

## 1. Audit it before you build

- The passage: count the words yourself. Does the count match the heading and
  `passage_words`? Inside 500–535?
- **Is anything in it real?** This is the lesson about false claims spreading,
  and it must contain no real organisation, no real figure, no real link and no
  date lifted from reporting. Search the passage for anything that looks like a
  real institution or statistic. This is the one check in this phase that
  cannot be skipped.
- The fourteen key words: all in the passage, none among those already taught
  (`python scripts/course_state.py --words`).
- The five recalled words: all from **Lesson 9**, and actually used inside the
  lesson rather than only listed. *estimate*, *verify* and *source* are the
  ones the subject needs.
- Part 04: does it open with the come-back to Lesson 9's passive? Does it make
  the point that reported speech names the source and the reporting passive
  deletes it? Does it credit the past perfect to Lesson 10?
- Part 06: ten questions, eight types, distractors wrong for nameable reasons.
- Is reported speech in the passage before part 04 names it?

Fix what is wrong in `lesson.json`, re-run `--check`, and report every change.

## 2. Build it

    cd lessons/lesson-11 && python build.py --build

About 210 segments and twelve sheets. Re-run it if the connection drops; the
audio cache means you only pay for what had not finished.

## 3. Read what came out

- `--plan` again: every file with its size, the folder total. Under 20 MB.
- Look at three PDFs — the passage, part 04, the answer key. Page breaks not
  landing inside a question, insertion markers printed, Arabic not reversed,
  footer right.
- Check the pauses in `02-listening-questions.mp3` are long enough to write in.
- Open all five games. The crossword must carry all nineteen words; the memory
  game's drawings must appear. `build.py` reports a word that will not fit a
  grid — do not let that message pass.

## 4. Catalogue and worker

    python make_catalog.py
    python scripts/build-sw.py

Confirm the catalogue lists `lesson-11` with twelve parts and its real size.

## 5. Commit

Everything, including the generated media and the lesson's own `README.md`. One
commit, house style, no push.

## Acceptance

- `--check` and `--plan` clean and pasted; folder under 20 MB, figure pasted.
- `python .claude/autopilot/check_lessons.py --built` passes, pasted.
- Catalogue and worker regenerated; catalogue lists lesson-11.
- Three PDFs and five games seen with your own eyes, and the progress file says
  what you saw — including the result of the "is anything in it real" check.
- Working tree clean, committed on `main`, not pushed.
