# Phase 01 — Build Lesson 10, and read what came out

Lesson 10's `lesson.json` exists. This phase turns it into sheets, audio and
games, and then — the part that matters — **reads the result** rather than
assuming it. You did not write this lesson; that is the point of doing it in a
separate phase.

## 1. Read before you build

    cd ~/work/shams/esl && export PATH="$PWD/.venv/bin:$PATH"
    cat docs/LESSONS-10-12-PROGRESS.md
    cd lessons/lesson-10 && python build.py --check && python build.py --plan

Read `docs/LESSONS-10-12-BRIEF.md` §"Lesson 10" too, so you know what the
lesson was supposed to be before you judge what it is.

**Audit it against the brief now, while nothing is built.** Specifically:

- The passage: count the words yourself. Does the count match the heading and
  `passage_words`? Is it inside 500–535?
- The fourteen key words: does every one appear in the passage? Is any one of
  them among the 124 already taught (`python scripts/course_state.py --words`)?
- The five recalled words: all from Lesson 8? Are they actually used inside
  this lesson, or only listed?
- Part 06: ten questions, the eight types, each distractor wrong for a nameable
  reason.
- Part 04: does it open with the come-back to Lesson 8's conditionals? Does it
  teach the trap — that a sequence in order needs no past perfect?
- The past perfect: is it in the passage before part 04 names it?

Fix what is wrong **in `lesson.json`**, then re-run `--check`. Report every
change you made. Finding nothing is a possible outcome; finding nothing in
every category means you did not really look.

## 2. Build it

    cd lessons/lesson-10 && python build.py --build

That is about 210 spoken segments and twelve sheets: real minutes. If the
connection drops, run it again — every segment is cached by its text in
`.audio-cache/` and the build carries on from where it stopped.

If WeasyPrint reports a layout problem, fix the Markdown that caused it. Do not
work around it by editing a PDF: the files it writes are generated and the
guard will refuse you.

## 3. Read what came out

- `python build.py --plan` again: every file, its length, its size, the folder
  total. Paste it. The folder should be about 18 MB and must be under 20 MB.
- Open two or three of the PDFs and actually look at them: the passage, the
  grammar part, the answer key. Check that a page break has not landed in the
  middle of a question, that the insertion markers are printed, that the Arabic
  in the vocabulary sheet is not reversed, that the footer carries the lesson
  name.
- Listen to the structure of the audio, by reading the segment list against the
  built durations: `02-listening-questions.mp3` should have a real pause after
  each question, long enough to write an answer in. If a pause is under five
  seconds, it is decoration.
- The five games: open each HTML and check the grid built, that the crossword
  has every one of the nineteen words, and that the memory game's drawings
  appear. `build.py` says so if a word would not fit a grid — do not let that
  message pass.

## 4. The catalogue and the worker

From the repository root:

    python make_catalog.py
    python scripts/build-sw.py

`make_catalog.py` will also move about forty byte figures in lessons 1 to 9.
That is not your doing and not a mistake: those numbers were last measured on a
Windows working copy where the generated HTML carries CRLF, and on Linux the
same committed files are about 0.7% smaller. Mention it in the progress file
and leave it; the Linux figures are the ones GitHub Pages actually serves.

Confirm the catalogue lists `lesson-10` with twelve parts and its real size.

## 5. Commit

Everything: `lesson.json`, the PDFs, the MP3s, the games, the lesson's
generated `README.md`, `app/catalog.json`, `sw.js`. The generated media **is**
committed in this repository, on purpose, so the student can download one file
without running anything.

One commit, in the house style — look at `git log`. "Add Lesson 9, which
completes the question set" is the voice; "Phase 01" is not.

## Acceptance

- Every file the lesson promises exists and is non-empty; the folder is under

- `python .claude/autopilot/check_lessons.py --built` passes, output pasted.
- `python make_catalog.py` and `python scripts/build-sw.py` run clean, and the

- You looked at at least three PDFs and all five games with your own eyes, and
  the progress file says what you saw.
- Working tree clean, committed on `main`, not pushed.
